## 1. `[XSIM 43-4323] No Change in HDL` — benign, but know the trap

XSim hashed your sources, saw nothing had changed since the last elaboration, and skipped recompiling — it just relinked the existing `.obj` files. It's an incremental-compile speedup, and in your case it's telling the truth: you hadn't touched the HDL.

**The trap it sets:** this is the number-one cause of "I edited my testbench and the waveform didn't change." If Vivado misses your edit — you saved outside the IDE, the file isn't actually in the sim fileset, a timestamp didn't move — you get this exact message and then sit staring at a stale run. The message is your only clue.

When you suspect that, force a clean build:

```
Flow → Simulation → Reset Simulation, then Run Simulation
```

or in the Tcl console:

```bash
reset_simulation -simset sim_1 -mode behavioral; launch_simulation
```

You won't see it on your next run anyway — I just changed the HDL, so it will genuinely recompile.

## 2. Nanoseconds — you had no `timescale at all

I grepped all ten files: **not one had a `timescale directive.** You were running entirely on XSim's built-in default.

You got lucky. Your own log proves the default is 1ns/1ps here: four `#10` delays put `$stop` at 40,000 ps, so one time unit = 1 ns exactly as you intended. But that's the tool's default, not your code's instruction — Icarus defaults to 1s/1s, and Questa errors out if some modules have a timescale and others don't. Same source, different answers.

Added to all 10 files (design + testbenches):

```verilog
`timescale 1ns / 1ps
```

Originals backed up to the scratchpad if you want to compare. CRLF line endings preserved.

**For the ruler to actually read `ns`:** the unit is still 1 ps precision, so set the display explicitly — the **gear icon** at the top-right of the waveform pane → **Waveform Options → General → Time Units → ns**.

*(`timescale 1ns / 1ns` would make the ruler read ns with no GUI step, but you'd lose sub-ns resolution the moment you model a real gate delay like `#0.5` — it'd silently round. Not worth the habit.)*
