## 3. Traps. Read this section before touching anything.

Every one of these cost real time. They are not hypothetical.

1. **`validate_simple()` returns 1 for pass, 0 for fail** — the opposite of the
   natural reading.
2. **Validate checks for conflicts, not correctness.** An imported shell landed
   500 mm off to the side and Validate passed, because a body floating in clear
   air intersects nothing. The only symptom was the air box growing from 310 mm
   to 810 mm in X. **Always re-read bounding boxes after any import or move.**
3. **Fusion component origins lie.** `New Shell:1`'s local origin is 500 mm from
   the body. Centre on the body's own bounding box, never on the origin.
4. **`analyze_setup()` returns `True` even when the solver never started.**
   Check `setup.is_solved`. Check `sweep.is_solved` separately — the setup can be
   solved while its sweep is not, which is exactly the current state.
5. **`create_setup` and `create_linear_count_sweep` auto-suffix rather than
   overwrite.** Three re-runs produced `SolveAllBands`, `_2`, `_2_3`, `_2_3_4`,
   and `Analyze All` would have solved all four identically. The sweep became
   `WideSweep_9YUHVQ`, so every report asking for `WideSweep` failed with
   *"Setup doesn't exist in this design"* — a message that blames the wrong
   object. **Always read the live name via `app.oanalysis.GetSweeps(setupName)`.**
6. **`app.setups` is a cached Python list** and is stale immediately after
   creating a setup. Use `app.oanalysis.GetSetups()`.
7. **Never touch `Object3d.faces` on the perforated shell.** PyAEDT builds a
   FacePrimitive per face and requests each centroid; on the 2184 NURBS faces
   that throws *"Failed to compute face center as the face is not planar"*,
   which looks like a geometry fault but is only a reporting call. Use
   `app.modeler.oeditor.GetFaceIDs(name)`.
8. **Deleting a port's sheet does not delete the port.** Clear boundaries
   explicitly or you get `GnssPort_0KLOX7` and overlapping-port errors.
9. **Do not use library `steel_1008`.** Nonlinear B-H permeability, HFSS rejects
   it outright. A linear `CellSteel` is defined instead.
10. **Explicit HPC settings can break the solve.** `cores=8, tasks=1,
    use_auto_settings=False` produced *"Unable to start analysis on machine
    'Local Machine'"* and the engine never started. Default settings work.
    `StartSolve.py` has `UseExplicitHpc = False` for this reason.
11. **A stuck COM engine survives everything but a reboot.** Two runs failed to
    start with no useful message; a laptop restart fixed it with no model change.
12. **The design is solution type `Terminal`, not Modal.** S-parameters are
    `St(CommPort,CommPort)`, and reports need
    `report_category="Terminal Solution Data"`.
13. **`Desktop.release_desktop()` takes `close_on_exit`; `Hfss.release_desktop()`
    takes `close_desktop`.** Different signatures, same-looking method.
14. **The C: drive filled to 0 bytes twice** from an Autodesk updater loop. Fixed
    and documented in `C:\Users\kalbh\Documents\OdisGuard\ReadMe.txt`. Check free
