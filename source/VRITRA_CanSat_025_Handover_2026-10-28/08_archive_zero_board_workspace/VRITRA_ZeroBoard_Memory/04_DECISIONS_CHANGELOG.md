## AI working rules (non-negotiable — this is a flight project)
1. Read 01, 02 and 03 in full before answering any wiring/pin/code question.
2. Never assign a pin from memory alone. For every new/changed pin check, in order:
   capability (§0 of 03: UART/SPI/I²C/PWM/analog), conflict with an existing net, shared PWM submodule,
   voltage domain (3.3 V I/O, ICM-20948 1.8 V pins), boot/strapping pins (XIAO GPIO0/3/45/46, Teensy On/Off & Program),
   I²C address collision, power budget of the rail.
3. If a module fact is not verified (status U/Q in 02), say so and ask — do not guess.
4. Before editing code or a schematic: read the WHOLE file first, change only what was asked, log it here.
5. Radio parameters are fixed by the organiser: 866.50 / 865.25 MHz, SF9, BW125, CR4/5, sync 0x99.
